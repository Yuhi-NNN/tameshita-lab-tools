YouTube チャンネル運営のための個人用ツール

このツールは、運営者が自分の YouTube チャンネルを管理するためだけに使う個人用のデスクトップツールです。一般の利用者向けには提供していません。

対象チャンネル

  • 数字で見る海外の反応
  • ずんめたAI実験室

できること

  • 運営者自身のチャンネルへの動画の予約投稿、サムネイル・タイトルの更新
  • 運営者自身のチャンネルの再生数・視聴時間などの分析データの取得
  • 公開されている動画コメントの取得（集計のため。投稿者名は保存しません）

本ツールは YouTube API サービスを利用しています。
